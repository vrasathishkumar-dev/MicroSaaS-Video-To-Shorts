# Autonomous Execution & Project Guidelines

- Run inspection, build, testing, server startup, and local dev commands directly without interactive prompts.
- Only pause to ask the user when there are major architectural changes, destructive file deletions, or critical design decisions.
- Maintain high code quality, clean UI/UX, and robust end-to-end integration across FastAPI and React.
